## Proyectos

| Carpeta | Descripción | Stack |
|---|---|---|
| [`bts-concert-app/`](./bts-concert-app) | Clon funcional de una app de conciertos (BTS World Tour 2026 · Lima): login, entrada digital con QR dinámico, guía del evento y perfil. Responsive con modo oscuro. | React 19 · Vite 8 · Tailwind CSS 4 · Express 5 |

### Arranque rápido

```bash
cd bts-concert-app
npm install
npm run dev:all      # API (4000) + frontend (5173)
```

Las instrucciones completas, incluida la vista previa desde el celular en la red
local, están en [`bts-concert-app/README.md`](./bts-concert-app/README.md).
